# Halloween Memory Challenge 🎃

Juego interactivo de memoria con tematica de Halloween, desarrollado en HTML5, CSS3 y JavaScript moderno con animaciones fluidas y diseno responsive.

## 🚀 Despliegue en Servidor

Para clonar y mantener este proyecto activo en tu servidor:

### 1. Clonar el repositorio por primera vez en tu servidor:
```bash
git clone https://github.com/Darkness0550/halloween-memory-challenge.git
cd halloween-memory-challenge
```

### 2. Actualizar cambios en el servidor en cualquier momento:
```bash
git pull origin main
```

### 3. Servir el proyecto:
El archivo principal es `index.html`. Puedes servirlo directamente con:
- **Nginx / Apache**: Apuntando el `root` del virtualhost a la carpeta del proyecto.
- **Node (serve / http-server)**: `npx serve -s . -l 3000`
- **Python**: `python3 -m http.server 8080`
- **Docker / Caddy** o cualquier servidor web estático.
